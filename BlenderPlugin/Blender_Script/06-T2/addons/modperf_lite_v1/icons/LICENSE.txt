The icons in this folder (blender_icons.bin / blender_icons.json) are Blender's
own user-interface icons, taken from the Blender 5.2.2 source code
(release/datafiles/icons_svg, https://projects.blender.org/blender/blender)
and rasterised for use by this add-on.
