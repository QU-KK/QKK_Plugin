# Py脚本工具 Pro（Uzima）

用 [Uzima UI](https://superhivemarket.com/products/uzima-blender-modern-ui/) 重新实现的「按钮小工具pro」面板：
把 `Python脚本/` 文件夹里的 .py 文件自动排成分类按钮，点一下就运行。

- 原插件：`按钮小工具pro`（Blender 自带面板绘制）
- 本插件：同样的数据、同样的布局规则，改用 Uzima 自绘 UI

## 安装

1. Blender 4.2 及以上（开发与测试使用 Blender 5.2.2 LTS）。
2. `编辑 > 偏好设置 > 获取扩展` → 右上角下拉菜单 → **从磁盘安装…**，选择
   `py_script_tool_pro-1.0.0.zip`。
3. 在扩展列表中启用 **Py脚本工具 Pro (Uzima)**。
4. 在 3D 视图按 `N`，打开侧栏的 **Python** 标签页。

> 如果同时启用了原来的「按钮小工具pro」，两个插件都会占用 `Python` 标签页。
> 建议只保留一个：原插件名称是 `Py_Script_Tool`，在偏好设置里禁用它即可。

## 界面

| 区域 | 说明 |
| --- | --- |
| 标题 / 副标题 | 插件名，以及「N 个分类 · N 个脚本」统计 |
| ↻ 图标按钮 | 重新扫描 `Python脚本/` 并刷新界面 |
| 文件夹图标 | 在资源管理器中打开 `Python脚本/` |
| 调试模式开关 | 开启后点击脚本只在资源管理器中**定位**，不执行 |
| 分类按钮（4 列） | `Python脚本/` 下的一级文件夹，去掉 `01-` 前缀显示 |
| 内容区 | 当前分类的脚本按钮，按文件夹名里的布局规则排布 |

脚本执行成功 / 失败都会在 3D 视图底部弹出提示；失败时完整堆栈会打印到
Blender 的系统控制台（`Window > Toggle System Console`）。

## 命名规则（与旧插件一致）

一级分类文件夹：`01-工具`、`02-模型检查`……（按钮显示 `-` 后面的名字）

布局文件夹（分类里的子文件夹）：

| 文件夹名 | 布局 |
| --- | --- |
| `01-列` | 一列 |
| `02-列-框` | 一列，外面加框 |
| `03-行-2-框-对齐` | 每行 2 个，加框，对齐间距 |
| `05-行-2--对齐` | 每行 2 个（空段等价于没有图标） |

脚本文件：`序号-名称-图标-高度.py`

- `1-清理层级-X-1.2.py` → 按钮「清理层级」，图标 X，高度 1.2 倍
- `5--TRASH-1.py` → 只有垃圾桶图标
- `1-提效工具--题头.py` → 变成小标题「提效工具」，不是按钮
- 直接放在分类文件夹里的 .py（不套布局文件夹）→ 整行普通按钮

文件名里的 Blender 图标名（`X`、`TRASH`、`UV`、`MATERIAL`……）会映射到
Uzima 的矢量图标；不认识的图标名会留空，与旧插件行为一致。

## 目录

```
py_script_tool_pro/
├── __init__.py              # 插件入口 (bl_info + register)
├── blender_manifest.toml    # Blender 4.2+ 扩展清单
├── tool.py                  # 面板、扫描、执行逻辑
├── Python脚本/              # 你的脚本库（随包附带 127 个脚本）
├── uzima/                   # Uzima UI 库 (GPL-3.0-or-later, Inter 字体 OFL-1.1)
└── LICENSE.txt              # GPL-3.0-or-later
```

## 开发

把整个文件夹放到 `scripts/addons/` 下（或安装 zip），修改 `tool.py` 后重新启用插件。
Uzima 的界面在每次重建时重新求值，改完脚本名 / 文件夹名后点刷新按钮即可看到变化。
